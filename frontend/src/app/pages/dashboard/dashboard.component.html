Ciclo Formativo en Desarrollo de Aplicaciones Web

El Ciclo Formativo de Grado Superior en Desarrollo de Aplicaciones Web (DAW) es una formación oficial de Formación Profesional de 2 años de duración.

🎯 Objetivo del Ciclo

Capacitar al alumnado para desarrollar, implementar, mantener y desplegar aplicaciones web, tanto del lado del cliente (front-end) como del lado del servidor (back-end), con acceso a bases de datos y siguiendo estándares de calidad, usabilidad y accesibilidad.

🏆 Título Oficial

Al finalizar obtienes el título oficial de Técnico Superior en Desarrollo de Aplicaciones Web — una titulación reconocida en toda España y compatible con estudios posteriores.

💼 Salidas Profesionales

  • Desarrollador/a web (Front-end y Back-end)
  • Programador/a web y multimedia
  • Especialista en despliegue y mantenimiento web
  • Consultor/a técnico inicial en proyectos digitales

🧑‍🎓 Requisitos de Acceso

  • Tener Bachillerato o equivalente
  • Haber superado una prueba de acceso para grado superior
  • Tener un título de FP medio o equivalente
